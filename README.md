# AI-CHAT-BOT
AI Chatbot with Streamlit & Gemini Pro

This project is a simple AI Chatbot Web App built using Python's Streamlit framework and powered by Google's Gemini-Pro model via the google.generativeai API. Users can interact with the AI in real-time by asking questions through a clean, minimal web interface.

---

Features
-  User input box for asking questions
-  Real-time AI-generated responses
-  Powered by Gemini-Pro from Google
-  Interactive and lightweight Streamlit UI
-  Input validation and smooth UX

---

 Tech Stack

| Layer       | Technology                |
|-------------|---------------------------|
| Language    | Python                    |
| Framework   | Streamlit                 |
| AI Model    | Gemini-Pro                |
| Hosting     | Localhost / Streamlit Cloud |
